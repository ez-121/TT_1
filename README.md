# StyleHub Clothing Store

A React clothing store assignment demonstrating:
- `map()` to render products
- React Router `Routes` and `Route`
- Dynamic routes using `/products/:id`
- `useParams()` to read the product ID
- `find()` to retrieve a product by ID
- Product images on the home and details pages

## Run the project

1. Open this folder in VS Code.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

Product images are stored in `public/images/`.
